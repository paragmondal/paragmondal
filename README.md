The cards above rely on a shared free service, so they can occasionally go down. The permanent fix is to generate them yourself with a GitHub Action that runs on a schedule and commits a static SVG straight into this repo — no external server, no rate limits.

1. In this repo, go to **Actions → New workflow → set up a workflow yourself**.
2. Use the [`github-readme-stats` Actions guide](https://github.com/anuraghazra/github-readme-stats/blob/master/readme_deploy_on_vercel.md) or a ready-made action like [`vn7n24fzkq/github-profile-summary-cards`](https://github.com/vn7n24fzkq/github-profile-summary-cards), which builds SVGs on a cron schedule and commits them to your repo.
3. Reference the committed SVG file directly in this README instead of the external URL, e.g. `![](./profile-summary-card-output/dark_stats.svg)`.

This is more setup, but it means your stats render from your own repo and can't be broken by someone else's server.
